# 💳 GridFinance System (Machine Learning)

## 📌 Project Overview

GridFinance System is a supervised Machine Learning project developed to predict loan approval status based on applicant information. The project focuses on building an end-to-end ML pipeline including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

The system leverages multiple classification algorithms to analyze applicant data and determine whether a loan should be approved or not.

# 📂 Dataset Information

The dataset contains applicant-related financial and personal information used to predict loan approval status.

### Dataset Features Include:
- Applicant Income
- Co-Applicant Income
- Loan Amount
- Loan Term
- Credit History
- Gender
- Marital Status
- Education
- Property Area
- Loan Status (Target Variable)

> Note: Dataset used for educational and learning purposes.
